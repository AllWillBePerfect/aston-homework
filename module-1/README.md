# Задание

Реализовать свой иммутабельный класс, который будет внутри себя содержать поле с изменяемым классом.

Сделал две реализации: обычный класс и `record`. В `Main` содержиться пример, что их состояние нельзя изменить снаружи.

# Структура

Классы в проекте:

- `Author` изменяемый класс автора;
- `ImmutableBook` иммутабельная книга в виде обычного класса;
- `ImmutableBookRecord` иммутабельная книга в виде `record`;
