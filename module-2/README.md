## Задание

1. Создать класс Student, содержащий список книг List<Book>. У каждого студента должно быть не менее 5 книг.

2. Создать файл с данными о студентах и книгах.

3. Считать данные из файла средствами Java и заполнить коллекцию List<Student>.

4. Обработать полученную коллекцию с помощью одной цепочки Stream API:

    * вывести в консоль каждого студента;
    * получить книги каждого студента;
    * объединить книги всех студентов;
    * отсортировать книги по количеству страниц;
    * оставить только уникальные книги;
    * оставить книги, выпущенные после 2000 года;
    * ограничить результат тремя книгами;
    * получить годы выпуска книг;
    * с помощью короткого замыкания получить Optional с годом выпуска;
    * вывести найденный год или сообщение об отсутствии подходящей книги.

# Структура

Классы в проекте:

* `Book` - модель книги;
* `Student` - модель студента, содержащая список книг.
* `StudentJsonParser` - чтение и парсинг JSON-файла.
* `StudentService` - обработка студентов и книг с помощью Stream API.
* `Main` - запуск программы и демонстрация работы.

Данные находятся в файле `students.json`.

### Тесты

В проекте также реализованы два тестовых класса:

* `StudentJsonParserTest` - проверяет корректность чтения и парсинга данных из json файла.
* `StudentServiceTest` - проверяет работу stream api, включая сортировку, удаление дубликатов, фильтрацию и обработку Optional.

# Примечание

Изначально планировалось сделать две реализации чтения данных - из json и xml, а затем добавить отдельную реализацию с postgres и flyway.

После обсуждения задания было решено отказаться от этого варианта, так как для текущего задания такая архитектура получалась избыточной. Было решено оставить вариант с чтением данных из json файла.
