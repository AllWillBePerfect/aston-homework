
## Задание

1. Реализовать программы, демонстрирующие возникновение Deadlock и Livelock.
2. Создать два потока, которые бесконечно выводят в консоль "1" и "2" по очереди, начиная с "1".

## Структура

- `Deadlock.java` - демонстрация взаимной блокировки двух потоков через `synchronized` на разных объектах, захватываемых в обратном порядке.
- `Livelock.java` - демонстрация livelock: потоки уступают друг другу ресурсы и не могут завершить работу.
- `SyncPrint.java` - два потока поочерёдно печатают "1" и "2" с использованием `wait()`/`notifyAll()`.

## Как запустить

В `Main.java` раскомментировать одну из строк:

```java
runDeadlock();
runLivelock();
runSyncPrint();
```

и запустить `Main`.
